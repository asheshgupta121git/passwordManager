# passMan
Welcome to the Pass Man project! This application is built using React.js and styled with Tailwind CSS, featuring stunning animated icons from Lord Icons to enhance the user experience.

# Overwiew
Pass Man is a password management tool designed to help users securely store and manage their passwords. With an intuitive interface and engaging animations, Pass Man makes password management easy and fun.

# Features
- Secure Password Storage: Keep your passwords safe with encryption.
- User-Friendly Interface: Built with React.js for a responsive and dynamic experience.
- Tailwind CSS: Enjoy a modern and clean design that is easily customizable.
- Animated Icons: Use of Lord Icons to provide a visually appealing experience.
- Dark Mode: Toggle between light and dark themes for a personalized experience.


# Getting Started
# Prerequisites
Make sure you have the following installed on your machine:

- Node.js (version 14 or higher)
- npm (Node Package Manager)

  # Installation
- 1. Clone the repository:
  git clone https://github.com/yourusername/pass-man.git
- 2. Navigate into the project directory:
  cd pass-man
- 3.Install the dependencies:
  npm install
- 4. Start the development server:
  npm run dev

Your application should now be running on http://localhost:3000.

# Usage
- Add Passwords: Easily add new passwords with the click of a button.
- View Passwords: Access and view your stored passwords securely.
- Edit/Delete Passwords: Modify or remove passwords as needed.
